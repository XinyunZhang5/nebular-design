# torch/torchvision, split by platform.
#
# On Linux, the default PyPI wheel drags in ~2.9 GB of NVIDIA CUDA packages
# (cudnn, cublas, cusparse, nccl, ...). Railway containers have no GPU, so not
# one byte of that is ever executed — it just makes the image 3.5 GB and slows
# every deploy. The +cpu build is the same PyTorch with that payload removed:
# 176 MB, and identical speed on a CPU-only box.
#
# macOS has no CUDA build at all, so there is no +cpu variant to ask for —
# requesting one fails outright. Hence the markers rather than a single pin.
--extra-index-url https://download.pytorch.org/whl/cpu
